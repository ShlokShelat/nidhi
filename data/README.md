# data/

Empty on purpose. The organizers' files contain real crisis posts and are not
redistributed here (see `docs/DATA_AND_ETHICS.md`).

To reproduce the submission, place `test.csv` here from the gated bundle, then
run `python tools/verify_bundle.py`. To score new posts, supply any CSV with the
header `row_id,anon_user_id,post_id,post`.
